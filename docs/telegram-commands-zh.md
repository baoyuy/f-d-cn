# Telegram 中文指令

本仓库默认使用 Telegram 中文交互层。配置中保持 `"language": "zh"` 时，机器人会显示中文键盘，并支持中文文本指令；英文 slash 命令仍然保留。

## 常用指令

| 中文指令 | 英文指令 | 用途 |
| --- | --- | --- |
| `帮助` | `/help` | 查看可用命令 |
| `状态` | `/status` | 查看当前持仓状态 |
| `状态表` | `/status table` | 以表格查看持仓 |
| `收益` | `/profit` | 查看累计收益 |
| `多单收益` | `/profit_long` | 查看多单累计收益 |
| `空单收益` | `/profit_short` | 查看空单累计收益 |
| `余额` | `/balance` | 查看账户余额 |
| `日报` | `/daily` | 查看最近每日收益 |
| `周报` | `/weekly` | 查看最近每周收益 |
| `月报` | `/monthly` | 查看最近每月收益 |
| `表现` | `/performance` | 查看交易对表现 |
| `持仓数` | `/count` | 查看当前持仓数量 |
| `启动` | `/start` | 启动交易循环 |
| `停止` | `/stop` | 停止交易循环 |
| `暂停` | `/stopentry` | 暂停新开仓 |
| `健康` | `/health` | 查看机器人健康状态 |
| `版本` | `/version` | 查看版本信息 |

## 管理类指令

| 中文指令 | 英文指令 | 用途 |
| --- | --- | --- |
| `强制退出 <交易ID>` | `/forceexit <trade_id>` | 立即退出指定交易 |
| `强制卖出 <交易ID>` | `/forceexit <trade_id>` | 立即退出指定交易 |
| `强制退出 all` | `/forceexit all` | 尝试退出全部持仓 |
| `强制做多 <交易对>` | `/forceenter <pair>` | 手动开多，需配置允许强制入场 |
| `强制做空 <交易对>` | `/forceshort <pair>` | 手动开空，仅合约/做空策略可用 |
| `黑名单` | `/blacklist` | 查看黑名单 |
| `黑名单 <交易对>` | `/blacklist <pair>` | 加入黑名单 |
| `删除黑名单 <交易对>` | `/blacklist_delete <pair>` | 从黑名单移除交易对 |
| `白名单` | `/whitelist` | 查看当前白名单 |
| `锁定` | `/locks` | 查看交易锁 |
| `解锁 <锁ID>` | `/unlock <lock_id>` | 删除指定交易锁 |
| `重载配置` | `/reload_config` | 重新加载配置 |
| `日志` | `/logs` | 查看最近日志 |

## 市场方向

`市场方向` 用于切换策略可接受的市场方向参数，支持中文别名：

| 中文参数 | 英文参数 |
| --- | --- |
| `做多` | `long` |
| `做空` | `short` |
| `震荡` | `even` |
| `无` | `none` |

示例：

```text
市场方向 做多
```

## 安全提醒

- 默认配置是 `dry_run: true`，模拟盘不会真实下单。
- 切换实盘前必须先回测，再跑一段时间模拟盘。
- 不要在公开截图、文档或聊天记录里暴露 Telegram Bot Token、交易所 API key 或服务器密码。
